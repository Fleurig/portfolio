# Municipality of Amsterdam — vignettes

I independently built the current version of the Municipality of Amsterdam's vignette platform. The platform consists of an application portal for citizens and a separate issuance app for store employees.

## What I did

- Built the entire front-end of the current version independently
- Complex form flows with conditional steps and validation logic
- UX decisions around error states, progress, and ease of use
- Focus on performance, accessibility, and maintainable code
